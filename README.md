# Araştırma Trend Radarı 📊

Manisa Celal Bayar Üniversitesi Büyük Veri Analistliği Programı - Kullanıcı Arayüzü Tasarımı Dersi Projesi.

OpenAlex ve arXiv API'leri kullanılarak akademik yayın trendlerini anlık olarak takip eden, Türkçe ve İngilizce dil destekli interaktif arayüz uygulaması.

## 🚀 Özellikler
* **Canlı Veri:** OpenAlex & arXiv API entegrasyonu ile haftalık yayın sayıları.
* **Filtreleme:** Türkiye adresli yayınları anında süzebilme.
* **Dinamik Ağ Grafiği:** Anahtar kelime eş-görünüm ağı (sürükle & yakınlaştır).
* **Erişilebilirlik & Performans:** Lighthouse testlerinde 90+ puan başarısı.
* **Çoklu Dil:** URL parametresi (`?lang=tr` / `?lang=en`) tabanlı dil seçimi.

## 🛠️ Teknolojiler
* Next.js 14 / React
* Tailwind CSS
* Recharts
* Vercel Deployment

## 🤖 Yapay Zekâ ve Akademik Dürüstlük Beyanı
Bu projenin geliştirilmesi, arayüz optimizasyonları ve erişilebilirlik (Lighthouse) düzenlemeleri sürecinde Yapay Zekâ Asistanı'ndan (LLM) fikir alışverişi ve kod iyileştirme desteği alınmıştır. Uygulanan tüm tasarım kararları, mantıksal kurgu ve test kontrolleri bizzat tarafımca yapılmıştır.
